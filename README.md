# AI Unbound

Portrait 2D strategy RPG for iOS and Android. The repository root is a Unity project targeting Unity `6000.3.25f1` (Unity 6.3 LTS).

## Open the project

1. Install Unity Hub and Unity `6000.3.25f1` with Android Build Support and iOS Build Support.
2. Add this repository folder as a project in Unity Hub.
3. Let Unity generate its default settings and package lock on first open.

Preproduction sources are in `docs/preproduction/`. Accepted technical decisions and current phase status are in `docs/architecture/DECISIONS.md` and `docs/STATUS.md`.
