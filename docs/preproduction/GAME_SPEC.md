핵심 게임 루프

1. Prepare: 스테이지 선택 및 획득한 재화(DataCoin)로 캐릭터 레벨업/스킬 강화.
2. Deploy: 3x3 그리드에 최대 5명의 캐릭터 배치 (전열/중열/후열).
3. Combat: 일반 전투 자동(Auto-battler). 보스전 돌입 시 플레이어가 수동으로 Active Skill 타이밍 제어(Interrupt/Burst).
4. Reward: DataCoin, 승급 칩셋(MemoryChip) 획득. 패배 시 패널티 없음.

승리/패배 조건

⚬ 승리: 제한 시간(90초) 내 모든 적 웨이브/보스 섬멸.
⚬ 패배: 모든 아군 캐릭터 사망 또는 제한 시간 초과(Time Over).

플레이 세션 길이

⚬ 1 스테이지: 60초 ~ 120초.
⚬ 1일 평균 세션: 15~20분 (Pay-to-progress 구조로, 막히는 구간에서 오프라인 방치 보상 또는 과금 결제로 허들 극복).

성장 루프

⚬ 스테이지 반복 클리어 (소탕 기능 지원, 과금/재화 소모) \rightarrow 재화 획득 \rightarrow 캐릭터 레벨업/스킬 티어 상승 \rightarrow 상위 스테이지 돌파.

전투 규칙 (요약)

⚬ 리얼타임 쿨다운(Tick-based) 시스템.
⚬ 공격 사거리와 배치 위치에 따라 타겟 우선순위 자동 결정.

보스전 규칙

⚬ 보스는 강력한 광역기 또는 즉사기를 사용 전 '캐스팅 바(Telegraph)' 표시.
⚬ 플레이어는 특정 캐릭터의 제어기(Stun/Silence) Active Skill을 수동으로 발동하여 보스 패턴 캔슬 가능.

UX 흐름

⚬ 타이틀 \rightarrow 메인 로비(기지) \rightarrow 캐릭터 관리 / 상점 / 맵 선택 \rightarrow 배치 화면 \rightarrow 전투 \rightarrow 결과(보상) \rightarrow 메인 로비.
