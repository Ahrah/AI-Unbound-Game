기본 스탯 및 전투 연산식

⚬ Tick Rate: 초당 10회 (0.1초 = 1 Tick).
⚬ 공격 속도 (ASPD): 기본값 1.0 (1초당 1회 공격). ASPD가 1.5면 0.66초당 1회 공격.
⚬ 데미지 계산식 (의사코드):
  float damage = attacker.ATK * (100f / (100f + target.DEF));
  damage = damage * Random.Range(0.95f, 1.05f); // 5% 편차
  
⚬ 치명타: 기본 치명타 확률(CRIT_RATE) 5%, 기본 치명타 피해(CRIT_DMG) 150%.
  if (Random.value < CRIT_RATE) { damage *= CRIT_DMG; }
  

타겟 선정 및 공격 순서

⚬ 일반 공격: 1순위: 나와 가장 가까운 열의 적. 2순위: 도발(Taunt) 상태인 적.
⚬ 스킬 타겟: 스킬 속성(가장 체력이 낮은 적, 가장 공격력이 높은 적, 광역 등)에 따라 독립적으로 타겟팅.

스킬 및 쿨다운

⚬ 모든 Active Skill은 쿨다운 타이머(초)를 가짐. 초기 마나(Energy) 개념 없이 전투 시작 시점부터 쿨다운이 돎.
⚬ 보스 스킬: 보스 Active Skill 쿨다운 완료 3초 전, 화면에 빨간색 인디케이터와 텍스트(예: "경고: 코어 과부하") 출력. 이 때 플레이어가 제어기(Stun/Silence) 캐릭터의 초상화를 탭하면 스킬이 취소되고 보스는 2초간 그로기(추가 피해 150%) 상태 돌입.
